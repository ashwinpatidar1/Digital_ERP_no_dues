# Digital No-Dues Clearance Management System

A full-stack web-based Digital No-Dues Clearance Management System designed to replace the traditional manual college clearance process.

The system allows students to submit and track their No-Dues applications while Academic, Placement, Accounts, Library, and Sports departments independently process their clearances. Once all department clearances are approved, the application is forwarded to the Director for final approval and certificate generation.

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt
- REST APIs

## Key Features

- Student, Faculty, and Director authentication
- Role-based access control
- Student No-Dues application submission
- Department-wise clearance tracking
- Faculty approval/rejection with remarks
- Application rejection and resubmission
- Automatic transition to Director approval
- Final Director approval
- Automatic certificate generation
- Certificate verification
- Audit logging
- Secure password hashing
- JWT-protected APIs
